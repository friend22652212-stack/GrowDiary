# GrowDiary 開發路線圖

## 第一階段（目前）— 核心 MVP ✅

- [x] 專案架構（SwiftUI + SwiftData）
- [x] 寶寶／寵物檔案 CRUD
- [x] 日記 CRUD（文字 + 多張照片）
- [x] 時間軸總覽
- [x] 本機照片儲存
- [x] App 圖示設計
- [ ] 基本 UI 視覺打磨

## 第二階段 — 成長數據

- [ ] 身高／體重／頭圍紀錄（寶寶）
- [ ] 體重紀錄（寵物）
- [ ] 成長曲線圖表
- [ ] 里程碑模板（第一次微笑、長牙、學走路等）
- [ ] 自訂里程碑

## 第三階段 — 進階功能

- [ ] iCloud / CloudKit 同步（多裝置）
- [ ] 搜尋與標籤
- [ ] 日記匯出（PDF / 相簿）
- [ ] 桌面 Widget（最新照片或年齡）
- [ ] 深色模式優化
- [ ] 多語系（繁中、英文）

## 第四階段 — 上架準備

- [ ] 隱私權政策網頁
- [ ] App Store 截圖與宣傳文案
- [ ] TestFlight 封測
- [ ] App Store 審核提交
- [ ] 使用者回饋迭代

## 建議優先順序（若資源有限）

1. 完成 App 圖示 + 基本 UI 打磨 → 可先做 TestFlight
2. 里程碑功能 → 差異化賣點
3. iCloud 同步 → 使用者留存
4. 匯出功能 → 家長剛需
